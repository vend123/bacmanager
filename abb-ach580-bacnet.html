BACnet Points List & Setup

// before you start

BACnet MS/TP is built in

🔌

Terminals X5

The embedded fieldbus is on the control unit: 29 B+, 30 A−, 31 DGND. Switch S4 TERM on at both ends of the trunk, and S5 BIAS on at one device, preferably at an end. For BACnet/IP the drive needs the FBIP-21 option module; otherwise go through a router or read MS/TP from a PC — see BACnet MS/TP over RS-485.

⚙

From the panel

Menu → Primary settings → Communication → Embedded fieldbus → Communication setup: EFB selection = BACnet MS/TP, Save, set the rows below, then Apply settings to embedded fieldbus. The same parameters are in group 58.

📋

What the drive serves

Per ABB's PICS: ReadPropertyMultiple and WritePropertyMultiple, COV with up to 5 subscriptions, max APDU 480, no segmentation. MS/TP master or slave, 9.6–115.2 kbps.

Group 58: the BACnet parameters

ParameterDefaultSet to
58.01 Protocol enableNoneBACnet MS/TP (2)

58.04 Baud rateAutodetect (for BACnet)The trunk's rate: 9.6, 19.2, 38.4, 76.8 or 115.2 kbps. Autodetect needs the parity in 58.05 right
58.05 Parity8 EVEN 18 NONE 1, which is what MS/TP uses

The device instance does not follow the MAC address: it is whatever 58.40 says. A drive that still answers as 4194303 was never commissioned for BACnet. Diagnostics are in 58.07–58.13: 58.07 has bits for wiring error (A/B swapped), parity and baud errors, no bus activity and comm loss; 58.13 counts the tokens the drive received. Defaults on this page are from ABB's firmware manual; check them against your drive's firmware version.

Hand start/stop and speed to BACnet

BACnet reads everything out of the box. To command the drive, point the control sources at the embedded fieldbus (EFB). Leave the rest at the factory defaults.

%

AV16 is a percentage

Input-Reference-1 runs from −150 to 150 %, and 100 % is the value in 46.02. With 46.02 = 60 Hz, 50 % is 30 Hz. Write 45 meaning hertz and the fan runs at 27 Hz.

☞

Control override

BV18 Control-Override-Command puts the drive under BACnet control from whatever its normal source is, without changing 20.01; BV19 shows it is active. The panel's HAND still beats it.

🔌

Relays, AOs and PID

BO0–BO5 drive RO1–RO5 and DO1 once their sources are the RO/DIO control word (10.99). AO0/AO1 need 13.12/13.22 = AO1/AO2 data storage. AV42 LOOP-Setpoint needs 40.16 = Setpoint data storage.

// the rule that bites

Writing once is not enough: 6681 EFB comm loss

ABB notes that BACnet has no timeout of its own, so the drive keeps one. Its defaults:

ParameterDefaultMeans
58.14 Communication loss actionFaultTrip on 6681 EFB comm loss when start/stop or the reference comes from the EFB
58.15 Communication loss modeCw / Ref1 / Ref2Only a write of the control word or a reference resets the timer — reading does not
58.16 Communication loss time30 s0–6000 s

So a BMS that writes Run and a speed once and then only polls the drive lets the timer run out, and 30 seconds later the drive trips. There are three ways out. Write the commands again well inside 58.16 — in BACManager a BACnet tag has Refresh (s), which writes the last value again every that many seconds until it is relinquished, and the free workspace sets 10 s on BV10 and AV16. Or set 58.15 to Any message, as ABB's own setup example does, so that polling keeps the link alive. Or choose Last speed or Speed ref safe (28.41) in 58.14 — with ABB's warning to make sure it is safe to keep running when communication breaks. After any change in group 58, Refresh settings in 58.06.

Tested against the simulated ACH580 with the comm-loss time shortened to 20 s: with Refresh 10 s the drive ran without a fault for the whole run; without it, MSV1 Active-Fault-1 went to Comm-Error about 20 s after the last write.

Discover the drive

On the BACnet tab open MS/TP on the PC's RS-485 port at the trunk's baud rate (or BACnet/IP behind a router or an FBIP-21) and press Discover. The drive appears with the instance from 58.40.

2

Open the workspace

Workspace → Open. The file reads device 1021; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Run, then command once

BACManager starts reading the drive by itself. On the Dashboard press Run, choose Run and set the reference — from then on both are written again every 10 seconds. After BACManager restarts, command them once more.

ABB ACH580 BACnet — FAQ

Where is the ABB ACH580 BACnet points list?+
In ABB's BACnet Protocol Implementation Conformance Statement for the ACH580, document 3AXD10000387059, in the ABB library. The table on this page lists the points a BMS uses most.
How do I enable BACnet on an ACH580?+
Set 58.01 Protocol enable to BACnet MS/TP, the node address in 58.03, the baud rate in 58.04 and a unique device ID in 58.40, then 58.06 = Refresh settings and save the parameters with 96.07. The Primary settings menu does the same under Communication → Embedded fieldbus.
Why does my ACH580 fault with 6681 EFB comm loss?+
By default the drive faults when no command or reference has been written for 30 seconds (58.14 Fault, 58.15 Cw / Ref1 / Ref2, 58.16 30 s) — reads don't count. Write the commands again regularly, or set 58.15 to Any message.
What is the ACH580's default BACnet device instance?+
4194303, which BACnet treats as invalid; it has to be set in 58.40 Device object ID. It does not follow the MS/TP address.
How do I set the ACH580's speed over BACnet?+
Set 28.11 Ext1 frequency ref1 to EFB ref1 and write a percentage to AV16 Input-Reference-1; 100 % equals 46.02 Frequency scaling. Start and stop with BV10 RUN-STOP-Command after setting 20.01 Ext1 commands to Embedded fieldbus.
Does the ACH580 support BACnet/IP?+
Not on the drive itself: the embedded interface is BACnet MS/TP. BACnet/IP needs the FBIP-21 adapter module, or a BACnet router in front of the MS/TP trunk.
