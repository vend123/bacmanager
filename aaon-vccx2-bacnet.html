// before you start

No BACnet card, but two RS-485 networks

🔌

BACnet is on board

The VCCX2 has its own BACnet MS/TP port — there is no AAON BACnet card to order. It is BTL listed as a B-ASC. For BACnet/IP there is the VCCX-IP controller, which has an Ethernet port as well as MS/TP terminals.

⚠

Not the “485” loop

The VCCX2 also has AAON's own communication loop (Unit ID 1–59, for Prism 2, MiniLink and CommLink). That loop is not BACnet. Wire the BMS to the BACnet port; a BACnet tool sees nothing on the other one.

🔢

Set on the LCD

The controller's 2×8 display and four buttons hold the BACnet settings: MAC address, device ID and baud rate, in the Settings screens.

// writing to the unit

Last write wins, and Auto is 65535

=

No priority array

The VCCX2's AVs are plain read/write values: a write replaces the value, whatever priority it was sent at, and stays after the BMS is gone. Two systems writing the same AV simply overwrite each other.

↺

Release overrides with Auto

An override stays until you write Auto back: 65535 for the fan VFD, the OA damper and the relief fan, 0 for Schedule Force, HVAC Mode Override and the supply setpoint override.

❄

The damper trap

Writing anything between 0 and 100 % to the OA Damper Override (AV:70) makes the controller treat the economizer as running short of 100 % — and it locks the compressors out. Set a minimum with Minimum Economizer Position (AV:49) instead.

AAON VCCX2 BACnet — FAQ

Where is the AAON BACnet points list?+
For units with the VCCX2 controller it is Appendix C, BACnet Guide, of AAON's VCCX2 Controller Technical Guide on aaon.com. The table on this page lists the points a BMS uses most.
Do I need an AAON BACnet card?+
No. The VCCX2 has an on-board BACnet MS/TP port. For BACnet/IP, AAON's VCCX-IP controller has an Ethernet port, or the MS/TP trunk can go through a BACnet router.
What are the VCCX2's default BACnet settings?+
MAC address 1 and 38400 baud. The device ID is entered on the LCD; AAON's guide gives no default, so set one per unit.
Why are the HVAC mode and occupancy analog inputs?+
That is how the VCCX2 reports them: AI:4 HVAC Mode, AI:3 Control Status and AI:2 Control Mode carry a number for each state, listed in the guide's enumeration tables (for example HVAC Mode 2 = Cooling).
How do I release a VCCX2 override from BACnet?+
Write Auto: 65535 to the fan VFD, OA damper and relief fan overrides, 0 to Schedule Force, HVAC Mode Override and the supply setpoint override.
Does the VCCX2 support COV?+
Not according to its published PICS (software 1.90 and earlier), which lists ReadProperty, ReadPropertyMultiple, WriteProperty and device management only, and no segmentation No. Its PICS lists ReadProperty, ReadPropertyMultiple, WriteProperty and device management only, and no segmentation, so a BMS polls it in small requests.mdash; so a BMS polls it in small requests.
