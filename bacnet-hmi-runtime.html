// what runtime is

BACManager to design, Runtime to deploy

An equipment builder ships the same unit many times. The engineer who builds the HMI needs the full tool; the units in the field only need to show that one panel and keep it running. A full licence on every unit makes no sense.

Runtime splits the two. You build the dashboard in BACManager — gauges, trends, alarms, setpoints bound to BACnet points or Modbus registers — then press 📦 to export a runtime package: the dashboard, a service PIN and a start-with-Windows choice in one .mmrt file. Installed on a panel PC, it turns that PC into a kiosk for your unit.

The package carries no network settings. Each unit keeps its own BACnet interface, port or MS/TP line, so one package fits the whole series.

// the way back in

Service with a PIN

To open serviceHow
With a keyboardCtrl+Shift+F12. On many laptops and compact keyboards F12 is a media key: press Fn+Ctrl+Shift+F12.
Without a keyboardHold a finger or the mouse on the top-right corner of the screen for 5 seconds.
Wrong PINFive wrong PINs in a row lock service for a minute.

Behind the PIN: the unit’s BACnet network (IP or MS/TP, interface, port, Who-Is target), the Modbus connection, another package, the licence, making the PC an ordinary one again, or closing the application. On a PC with a BACManager licence there is also Open the editor, with a way back to Runtime.

Locking Windows itself. No application can block the Windows key or Ctrl+Alt+Del. For a panel the operator must not leave at all, use Windows’ own kiosk features — Assigned Access, or Shell Launcher on Enterprise and IoT editions — with BACManager as the application it starts.

BACManager Runtime — FAQ

Does the unit find its BACnet devices by itself?+
Yes. The kiosk opens BACnet with the unit’s own settings, polls every device the dashboard’s BACnet points read, and sends Who-Is until each device has answered — every 30 seconds, so a controller that starts after the panel PC is still found. A Who-Is target (an IP or a range) can be set for devices behind a router.
Is Runtime a separate program?+
No. Every unit gets the normal BACManager installer. What makes a PC a runtime machine is the package installed on it; the Runtime key only licenses that use.
Do I need BACManager to make a package?+
Yes — the dashboard editor and the 📦 export are part of the full BACManager. One licence (or the free trial while you evaluate) is enough for any number of packages.
What happens without a licence?+
For the first 14 days the PC runs on the trial. After that the package runs for 2 hours at a time, then stops polling — BACnet and Modbus — and shows the Machine ID with an Activate button; a restart gives another 2 hours.
How do I get out of the kiosk?+
Ctrl+Shift+F12 (Fn+Ctrl+Shift+F12 on many laptops), or hold the top-right corner of the screen for 5 seconds, then enter the package’s service PIN.
What if the panel PC has a different screen resolution?+
By default the package fits the dashboard to the unit’s screen: scaled as a whole, keeping its proportions, and centred. If you prefer exact pixels, choose “Actual size (1:1)” when you export.
How do I update the dashboard on units already in the field?+
Export a new package in BACManager and install it through the service menu on each unit. Replacing a package needs that unit’s current service PIN.
How is Runtime licensed and bought?+
$39 one-time per machine, bound to that PC’s Machine ID. Order by e-mail at license@bacmanager.com with the Machine IDs; you pay an invoice and receive one key per machine.
