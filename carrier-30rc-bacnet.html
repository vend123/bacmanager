Carrier AquaSnap 30RC
BACnet Points List & Setup

// before you start

BACnet is in the Carrier Controller

🔌

No card, one Ethernet port

The Carrier Controller display is the chiller's controller and its BMS interface. Its RJ45 port J5 (ETH0) carries BACnet, Modbus TCP and the web interface. The BACNET menu offers BACnet/IP or BACnet MS/TP; the form does not say which terminal MS/TP uses on this chiller.

⚙

Off from the factory

The BACNET menu's bacena is 0 (disabled), and the factory configuration has bac_opt “Enable BacNet Option” = No. The form lists both without saying how they relate; the factory menu needs the Factory access level. If BACnet stays silent, ask Carrier service to check bac_opt.

🔑

Network control method

On the display's Start/Stop screen pick Network. In Local On, Local Schedule or Remote the chiller reads fine but ignores every network command except Emergency Stop. Start/stop from the web interface is not allowed at all, for security.

// setup

2

Start needs two things

Carrier's start/stop table lists the Network method as running only with Start/Stop enabled and the time schedule occupied. If BV 12 reads 1 and the chiller still stays off, check BV 58 — and write BV 10058 = 1, or occupancy through AV 66 with mng_occ = Yes.

°

Setpoint or control point

The chiller controls to the control point: the current setpoint plus any reset. SETPOINT_csp1 (AV 900, default 44.6 °F = 7.0 °C) is a plain read-write setting; GENUNIT_CTRL_PNT_wr forces the control point directly while Network is active.

8

Which priority

The form marks the _wr objects RW but does not say whether they carry a priority array or which priority a BMS should use. BACManager writes at priority 8 unless you choose otherwise; a commanded value stays until it is relinquished — see the priority array explained.

// the rules that bite

Network, 1600001, metric

NET

Only Network obeys

Local On, Local Schedule and Remote ignore BACnet start/stop, setpoint and demand limit writes. Read GENUNIT_CTRL_TYP (AV 21: 0 Local, 1 Network, 2 Remote) before blaming the BMS. Changing the method passes through Off, with the on-to-off delay.

#

Every chiller is 1600001

The manual device ID is 1600001 on every controller. Two 30RCs on one network answer Who-Is with the same instance until bac_id is changed on one of them (or the automatic scheme is set up).

°C

Metric by default

Metric Units? = Yes from the factory: BACnet reads °C and kPa while the display and the form's point tables give °F and PSI. A BMS that expects °F reads 7 as freezing. Pick one and label the points.

With Alarm Reporting enabled, BACManager can receive the alarm notifications the chiller sends; the form does not describe its alarm services or how the recipients are set.

The 30RC chiller workspace

One dashboard page for the chiller: the unit with compressors A1, A2, B1, B2, leaving and entering water and capacity; control type, running and alarm relay; circuit A refrigerant values; and the network commands at priority 8 — start/stop, occupied, control point, demand limit, emergency stop and cooling setpoint 1.

1

Discover the chiller

On the BACnet tab open BACnet/IP on the PC's network card and press Discover — from another subnet through the site's BBMD as a foreign device, or MS/TP on a USB RS-485 adapter if the chiller is set to MS/TP.

2

Open the workspace

Workspace → Open. The file reads device 1600001, the factory bac_id; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Network, then Run

Check the control type reads Network. On the Dashboard press Run: the commands write only in Run mode and only after the chiller has answered.

Carrier 30RC BACnet — FAQ

How do I enable BACnet on a Carrier 30RC?+
Give Ethernet 0 (J5) an address under System Menu → Network, then set Main Menu → Configuration → BACNET → bacena = 1 (BACnet IP) and a unique bac_id. The factory configuration also has an “Enable BacNet Option” (bac_opt, default No) that needs Factory access.
What is the default BACnet device ID of the Carrier Controller?+
1600001 (bac_id), with network number 1600 and UDP port 47808. The default IP address of J5 is 169.254.1.1.
Why does the 30RC ignore my BACnet start command?+
The Machine Control Method must be Network, and in Network the chiller runs only when Net.: Cmd Start/Stop is enabled and the schedule is occupied. Read GENUNIT_CTRL_TYP (AV 21) and GENUNIT_CHIL_OCC_rd (BV 58).
Which object is the chilled water setpoint?+
SETPOINT_csp1 (AV 900) and SETPOINT_csp2 (AV 901) are the cooling setpoints; GENUNIT_CTRL_PNT_wr (AV 10006) forces the control point directly in Network. AV 7 shows the current setpoint and AV 6 the control point in force.
Are the BACnet values in °F or °C?+
°C and kPa by default: the BACNET menu's Metric Units? is Yes from the factory, even though the display defaults to US Imperial. Set bacunit = No for °F.
Does the 30RC support BACnet MS/TP?+
The BACNET menu offers MS/TP (bacena = 2) with MAC 1, 38400 baud and Max Master 10 as defaults. The form does not show which terminal it uses on the 30RC; BACManager reads MS/TP from a USB RS-485 adapter.
