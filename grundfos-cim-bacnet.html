// before you start

A module in the pump

🔌

CIM or CIU

A CIM is a communication module that plugs into the pump's electronics — MAGNA3 and the E-pumps — on a 10-pin connector and takes its power from it. A CIU is the same module in a box of its own, for pumps that cannot take one inside. Grundfos' profile covers MAGNA3, E-pumps 0.25–7.5 kW and CUE / E-pumps 11–22 kW.

🌐

MS/TP: CIM 300. IP: CIM 500

CIM 300 speaks BACnet MS/TP. For BACnet/IP use the CIM 500 Ethernet module and turn its protocol switch SW1 to 2: from the factory it is 0, PROFINET IO. Turning it while powered restarts the module in the new protocol.

📋

What the module serves

B-ASC, ReadProperty(Multiple), WriteProperty(Multiple), COV with up to 10 subscriptions, DeviceCommunicationControl. Vendor ID 227. BTL-listed for the CIM/CIU 300, firmware 04.02.00. The control objects are writable, not commandable.

// control

Bus values first, then bus control

1

Set control source

BO0 Set control source is 0 local from the factory: the pump runs on its own settings and does nothing the BMS writes. Write 1 for bus control. BI0 and MI14 say who is in control; BI64 Forced to local says something on site overrides it.

2

…but not first

The bus values the pump takes over have factory values too: control mode constant speed and operating mode Stop. Grundfos' own example writes operating mode Start (MO1), the control mode (MO0) and the setpoint (AO0) first, and enables bus control last — otherwise the pump stops.

%

The setpoint is a percentage

AO0 is % of the setpoint range in closed-loop modes: actual = AO0 × (rmax − rmin) + rmin, with rmin and rmax = AI133 and AI134 × the sensor maximum AI86. Grundfos' MAGNA3 example: 5–50 % of 20 m is 1–10 m, so 40 % is 4.6 m. In constant speed it is % of nominal frequency, and 0 % does not stop the pump.

// the rule that bites

The watchdog that does not come back

⏳

Off from the factory

AV1 BACnet watchdog is 0, off: a pump on bus control stays on the last bus values forever if the BMS goes away. Set 5–3600 s to have it fall back to its local settings instead — after making those local settings right with Grundfos GO.

⚠

No way back by itself

After a watchdog time-out the pump stays on local control when BACnet returns. Grundfos: the user must set it back to bus control with BO0. A BMS that wrote BO0 once at commissioning never does.

↻

Write BO0 again

Writing BO0 = 1 cyclically brings the pump back on bus control as soon as the link is back.

In BACManager a BACnet tag has Refresh (s): the last value written to it is written again every that many seconds until it is relinquished. The free workspace sets 10 s on BO0 only. Tested against the simulated MAGNA3 with a 15-second watchdog and a 20-second link loss: both runs fell back to local control 15 s into the loss; with Refresh the pump was on bus control again 5 s after the link returned, without it it stayed on local control for the rest of the run.

The MAGNA3 workspace

One dashboard page for a MAGNA3 on a heating circuit: control source and CIM status, differential pressure, estimated flow, speed, relative performance, power and energy, the actual modes and fault codes — with the bus values to write first, bus control written again every 10 seconds, fault reset and the watchdog.

1

Discover the pump

On the BACnet tab open MS/TP on the PC's RS-485 port at the CIM 300's baud rate, or BACnet/IP for a CIM 500, and press Discover. The pump appears as 227000 plus its MAC.

2

Open the workspace

Workspace → Open. The file reads device 227005; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Bus values, then bus

On the Dashboard press Run. Choose Start, the control mode and the setpoint; then Bus. From then on BO0 is written again every 10 seconds. After BACManager restarts, write it once more.

Grundfos CIM BACnet — FAQ

Where is the Grundfos MAGNA3 BACnet points list?+
In Grundfos' “BACnet for Grundfos pumps” functional profile and user manual for CIM/CIU 300 and 500, document 97572650, which marks every object for MAGNA3, E-pumps and CUE. The table on this page lists the points a BMS uses most.
CIM 300 or CIM 500 for BACnet?+
CIM 300 for BACnet MS/TP. CIM 500 for BACnet/IP, with its protocol switch SW1 turned to 2; from the factory it is set to PROFINET IO.
What is the Grundfos CIM 300 default BACnet device instance?+
227000 plus the MS/TP MAC set on SW6 and SW7, while SW3 is off. With SW3 on, the instance is the value written to AV0.
Why doesn't my Grundfos pump respond to BACnet commands?+
Set control source (BO0) is 0, local, from the factory. Write the operating mode, control mode and setpoint first, then BO0 = 1 for bus control.
Why did my pump stay on local control after a network fault?+
The BACnet watchdog (AV1) put it on its local settings, and it does not return to bus control by itself. BO0 has to be written 1 again once the link is back.
How is the Grundfos BACnet setpoint scaled?+
In closed loop AO0 is a percentage of the setpoint range: actual = AO0 × (rmax − rmin) + rmin, where rmin and rmax are AI133 and AI134 times the sensor maximum AI86. In open loop it is a percentage of the nominal frequency.
