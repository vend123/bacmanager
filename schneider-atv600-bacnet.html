// before you start

BACnet is an option card

🔌

VW3A3725 in slot A

The ATV600 speaks BACnet MS/TP through the VW3A3725 fieldbus module, fitted in slot A with the power off. It needs drive software V1.7 or later. For BACnet/IP put a BACnet router in front of the trunk, or read MS/TP directly from a PC — see BACnet MS/TP over RS-485.

⚡

Wiring

A 5-pin block: signal common, Data−, shield, Data+. Daisy chain only, 120 Ω at both ends, wired on the terminal block. The module has no bias resistors, so bias has to come from another device on the trunk. It is half a unit load, so a segment takes up to 64 of them.

📋

What the drive serves

Per the manual and PICS: B-ASC, ReadPropertyMultiple, WritePropertyMultiple, COV, max APDU 480, MS/TP master only at Auto, 9600, 19200, 38400 or 76800 baud. BTL-listed for firmware V1.7.

The device instance does not follow the address: set INXP on every drive. The module's MS LED tells you its state: green blinking is normal, green triple flash waits for auto-baud, red double flash is an invalid configuration, red triple flash a communication interruption. The diagnostics menu shows the baud rate in use and the received, transmitted and bad frame counts.

Both, at least once

The channel is enabled only when every parameter it carries has been written at least once: the drive will not start on RUN/STOP CMD (BV10) until INPUT REF 1 (AV16) has been written too, and the other way round.

%

AV16 is a percentage

INPUT REF 1 is in %, and neither the manual nor the PICS says of what. Write 50, read OUTPUT FREQ (AV1) and the drive's own display, and scale your BMS point to match.

↺

Fault reset on an edge

FAULT RESET (BV14) acts on a rising edge. Writing Reset twice does nothing the second time: write No, then Reset.

// the rules that bite

One second, and a channel that switches itself off

1 s

Any message, every tLP

Once a command or reference has been written, the module expects a BACnet message at its address at least every tLP — 1.0 s from the factory. If none comes, the drive raises [Fieldbus Com Interrupt] CnF and, by default, stops freewheel. A busy MS/TP trunk easily leaves a drive alone for longer than a second.

⚙

Set tLP, then CLL

Raise tLP above your poll interval with margin — 10 s for a BMS that polls every few seconds. What the drive does on CnF is [Fieldbus Interrupt Resp] CLL: freewheel (factory), ramp, fast stop or DC injection as a fault, or fallback speed, speed maintained or stop without a fault. Schneider warns to use Ignore only for tests.

⚠

Then: write both again

A communication interruption disables the channel. After the fault reset the drive waits for the command and the reference to be written again — and reading BV10 still says Start, because a read of a commandable object is answered from the module's priority array, not from the drive.

In BACManager a BACnet tag has Refresh (s): the last value written to it is written again every that many seconds until it is relinquished. The free workspace sets 10 s on BV10 and AV16, so after a fault reset the drive gets both back on its own. Tested against the simulated ATV600 with an 8-second link loss: both runs tripped on CnF; after FAULT RESET the drive with Refresh was running again within 5 s, the one without stayed stopped for the rest of the run — with BV10 reading Start the whole time.

The ATV600 workspace

One dashboard page for an ATV600 on a chilled-water pump: hand/auto and fault as text, frequency, speed, current, power, DC bus, thermal state, energy and run time — with the start command and the reference written again every 10 seconds, and fault reset.

1

Discover the drive

On the BACnet tab open MS/TP on the PC's RS-485 port at the trunk's baud rate (or BACnet/IP behind a router) and press Discover. The drive appears with the instance from INXP.

2

Open the workspace

Workspace → Open. The file reads device 6002; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Run, then command once

BACManager starts reading the drive by itself. On the Dashboard press Run, choose Start and set the reference — from then on both are written again every 10 seconds. After BACManager restarts, command them once more.

Schneider ATV600 BACnet — FAQ

Where is the ATV600 BACnet points list?+
In appendix A of Schneider Electric's ATV600 BACnet MS/TP manual for the VW3A3725 module, document QGH66984, and in the Altivar Process ATV6x PICS. The table on this page lists the points a BMS uses most.
Does the ATV600 have BACnet built in?+
No. BACnet MS/TP comes with the VW3A3725 fieldbus module in slot A, on drive software V1.7 or later.
What is the ATV600's default BACnet address and instance?+
Both 0 from the factory: [Address] AdrC and [Instance nb] INXP. Set a free MS/TP address and a unique device instance on every drive.
Why does my ATV600 stop with CnF?+
[Fieldbus Com Interrupt] CnF means the module received no BACnet message at its address within [Fieldbus timeout] tLP, 1.0 s from the factory. Set tLP longer than the BMS's poll interval and choose the reaction in [Fieldbus Interrupt Resp] CLL.
Why won't the ATV600 restart after a fault reset?+
A communication interruption disables the control channel; the drive waits until the command and the reference have both been written again. Reading RUN/STOP CMD shows the module's stored value, not the drive's, so it can say Start while the drive waits.
How do I read any ATV600 parameter over BACnet?+
With the mailbox: write the parameter's logical address to MBOX PARAM (AV25), set MBOX READ (BV15), and read the value from MBOX DATA (AV26). Writing works the same way with MBOX WRITE (BV16).
