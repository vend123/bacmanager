Systemair Access
BACnet Points List & Setup

How to bring a Systemair air handling unit with the Access controller onto a BMS over BACnet/IP: switching BACnet/IP on (it leaves the factory off), the device ID that Systemair gives no default for, the 1201-object EDE list for Access 5.5, the temperatures that arrive without a unit, the BMS watchdog — and which setpoint the unit actually uses. With a free BACManager workspace.

// before you start

BACnet/IP is built into the Access controller

🔌

Ethernet, no gateway

The Access controller talks BACnet/IP on its own TCP/IP port. Access 4.0-1-05 brought BACnet as an application specific controller (B-ASC). From 4.3-1-00 it is an advanced application controller (B-AAC). Systemair's communication manual describes BACnet/IP only, with nothing on MS/TP.

i

Know your software version

Press the “i” button on the Access home page. The object lists for Access 4.x and 5.x are different, so download the zip that matches your unit. Systemair's download page also says that an upgrade to 5.5 from an earlier 5.x is not available yet; support is planned for the second half of 2026.

📋

What Systemair publishes

An EDE object list (1201 objects for 5.5-1-01) with state texts and unit codes, and a Modbus signal list that gives defaults. We found no PICS: BIBBs, segmentation, max APDU and protocol revision are not published. Older Systemair units with a Corrigo E controller are not covered here.

The EDE file that Systemair ships shows the instance 114112 in its device column and names the Device object “Access”. Treat that as the instance of the controller the file was exported from, not as a factory value: read the ID in the web interface or with a Discover. If the BMS reaches the unit through a router, the BBMD entry lets the controller be found from the other subnet. BACManager can also register itself as a foreign device with the site's BBMD.

// writing to the unit

Settings, not commands

Systemair's object list does not say which BACnet objects can be written: the EDE “settable” column is N for all 1201 rows. In the Modbus list the same signals are split into settings (S_ prefix: holding registers and coils) and actual values (A_: input registers). The table uses that split. Read the setpoint in use

SupplySetpoint (AV39) only applies in constant supply air mode. In the other modes the unit works out its own setpoint, from outdoor compensation, a room or extract cascade, or a speed offset. Watch SupplyPID_SetP (AV273), the setpoint actually in use, and not only the one you wrote.

8

Priority: not given

Systemair does not say whether these objects have a priority array, or which priority a BMS should write at. BACManager writes at priority 8 unless you choose another. Read the value back after writing, and see the priority array explained for how to hand a point back.

⏱

Values from the BMS expire

Once the BMS watchdog is set to BACnet, a quiet period longer than the timeout makes every value written by the BMS invalid and raises a watchdog alarm (class C, no action, by default). The BMS outdoor temperature gets a sensor-error alarm too. BACManager's per-tag “Refresh (s)” can rewrite AV466 regularly.

// the rules that bite

Off on delivery, no units, two object lists

Off

BACnet/IP is off

A new unit does not answer Who-Is until BACnet/IP is set to Yes, however good the network is. It is the first thing to check when Discover finds nothing.

95

Temperatures carry no unit

In the EDE, temperatures, pressures and air flows have unit code 95, “no units”. The number follows the temperature, flow and pressure units chosen in the controller's preferences, so the BMS has to be told whether 18 means °C or °F, and whether the flow is in m³/h or l/s.

4/5

4.x and 5.x lists differ

The 4.x manual builds instances from the Modbus address (10XXX/20XXX binary, 30XXX/40XXX analogue and multistate). The 5.5 EDE uses plain instances (AI3 is supply air). A BMS mapped for one version shows wrong values on the other.

The full list also holds heat pump, humidity, damper and fan fault bitmask objects, digital inputs and outputs, and the alarm limits. Systemair does not document how. BACManager's device alarms show whatever the unit sends. The EDE marks COV support on the analog objects.

The Access AHU workspace

One dashboard page for a Systemair unit with heat recovery, a heater and a cooler: the AHU with intake air, supply air, air flow and coil valves, both fans with pressure and speed, outdoor, extract and exhaust air, filter pressure, exchanger efficiency, SFP, a trend, and the running mode, supply setpoint, service stop and alarm acknowledge as controls.

1

Discover the unit

On the BACnet tab open BACnet/IP on the PC's network card and press Discover. The unit appears with the device ID set in its web interface. If it is on another subnet, register with the site's BBMD first.

2

Open the workspace

Workspace → Open. The file reads device 20201. If your unit has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Run

BACManager starts reading the unit by itself. On the Dashboard press Run to use the controls. They write only in Run mode, and only once the unit has answered. Check that SupplyPID_SetP follows what you wrote.

// questions

Systemair Access BACnet — FAQ

How do I enable BACnet on a Systemair Access controller?+
In the controller's web interface go to Configuration → Communication → BACnet and set BACnet/IP to Yes. Give the unit a unique BACnet device ID and a device name, keep UDP port 47808, and enter a BBMD address only if the BMS is on another subnet. BACnet is off on delivery.
What is the default BACnet device ID of an Access controller?+
Systemair does not state one; the manual only says the ID must be unique. The EDE file Systemair ships shows 114112, which looks like the instance of the controller it was exported from. Read the ID in the web interface or with a Discover, and set your own.
Where is the Systemair Access BACnet points list?+
On Systemair's Access software download page: “Access 5.x Modbus variables and BACnet objects” (or the 4.x zip for older units). For 5.5-1-01 it holds an EDE object list with 1201 objects, the state texts, the unit codes and the Modbus signal list.
Which object starts and stops the air handling unit?+
AirUnitAutoMode (MV12): 1 OFF, 3 AUTO on the time schedule, 4–6 a fixed speed. AirUnitServiceStop (MV32) and ExternalControl (MV31) can also stop it. UnitMode (MV15) shows what it is doing, and UnitModeControl (MV16) shows why.
Why do the temperatures come without a unit?+
The Access EDE exports temperatures, pressures and flows with unit code 95 (no units), and the value follows the units chosen in the controller's preference setting. Tell the BMS which unit that is.
Does the Access controller support BACnet MS/TP?+
Systemair's communication manual describes BACnet/IP over the controller's TCP/IP port and says nothing about MS/TP. For an MS/TP-only BMS, put a BACnet router between the two.
