Lochinvar Crest
BACnet Points List & Setup

How to put a Lochinvar Crest condensing boiler on BACnet MS/TP: the DIP switches on the MTR-01 BACnet board, the device instance it makes up, the Configuration bits that decide which values the boiler takes from the BMS — and the BAS timer that hands control back to the boiler when the writes stop. With a free BACManager workspace that writes them again every 10 seconds.

// before you start

One board, two settings on the boiler

🔌

The MTR-01 board

The Crest's communication board sits in the control panel and comes in a ModBus and a BACnet version. The BACnet one is an MS/TP master on RS-485 (A, B, shield). For BACnet/IP put a BACnet router in front of it, or read the trunk directly from a PC's RS-485 port — see BACnet MS/TP over RS-485.

⚙

Two menus

Main Menu → Setup → BMS sets the demand configuration: whether the enable, the BMS rate or setpoint, or both come over the network. Main Menu → Setup → BAS sets the BAS timer, 5–120 s.

°F

°C or °F

DIP switch 8 on the board picks the unit: off is Celsius, on is Fahrenheit. The memory map gives every range in °C, so a Fahrenheit job reads different numbers from the ones in the tables.

The base (610000 and so on) can be set by the integrator to anything from 0 to 4194048; the device instance is still base + MAC. Two boilers of the same model with the same MAC on two trunks therefore collide — give one of them another base. To go back to the factory base: power off the board, set DIP 1–8 on, power on, wait a few seconds, power off, set the address on DIP 1–7, power on. The green LED D7 tells you the board's state: 1 s bright / 1 s dim is normal, 1.5 s on / 0.5 s off means no BACnet communication, 0.5 s on / 1.5 s off no communication with the burner control, steady on a controller fault. D5 and D6 flash on transmit and receive.

// the bits that decide

Configuration (AV:0): which values come from the BMS

Each bit set to 1 tells the boiler to ignore its own input for that value and take the one the BMS writes. Nothing you write to AV:1–AV:7 counts until its bit is set. Lochinvar asks for the configuration to be sent again before every command.

1

Enable only

Setpoints stay on the boiler, the BMS only switches it. AV:0 = 1, AV:1 = 1 to enable, 0 to disable. Demand configuration ENABLE active, BMS inactive.

4

Rate or setpoint only

The BMS sends a firing rate or a setpoint on AV:2, all sensors stay wired to the boiler. AV:0 = 4. Demand configuration ENABLE inactive, BMS active.

5

Enable and setpoint

Both: AV:0 = 5, AV:1 bit 0 enables, AV:2 sets the rate or setpoint. Both ENABLE and BMS active. This is what the free workspace does.

// the rule that bites

The BAS timer: write again, or the boiler takes over

⏱

Temperatures: seconds

When the BMS provides the system supply or tank temperature, it has to update it every few seconds. If no new value arrives within the BAS timer (5–120 s), the boiler goes back to its own sensors, if it has them.

4

Commands: 4 minutes

When the BMS sends no temperatures but does control the boiler — an enable, a rate or a setpoint — Lochinvar's section 6 asks for the commands to be written again at least every 4 minutes. Its section 10 says every write of a command resets the BAS timer, and that the timer itself hands control back when it runs out.

↻

So: write faster than the timer

Write the configuration and the commands again well inside the BAS timer. Set the timer to, say, 30–60 s and write every 10 s: a missed write is retried twice before the boiler gives up on the BMS.

In BACManager a BACnet tag has Refresh (s): the last value written to it is written again every that many seconds until it is relinquished. The free workspace sets 10 s on Configuration, Coils and the setpoint command. Tested against the simulated Crest with a 20 s BAS timer: with Refresh the boiler stayed on BMS heat demand (status 22) for the whole run; without it, it dropped to its own control (status 11, no heat demand) within about 20 s of the last write.

// setpoint in percent

AV:2 is a percentage, not a temperature

AV:2 stands in for the boiler's 0–10 V input: 0–100 % means 0–10 V. Set up for a firing rate, it is the modulation; set up for a setpoint, the boiler scales it between two parameters.

BMS setpoint parameterDefaultAt
Temperature at low analog input69.8 °F (21 °C)2 V = 20 %
Temperature at high analog input179.6 °F (82 °C)10 V = 100 %

Volts = (setpoint − 69.8) × 8 / (179.6 − 69.8) + 2, and percent = volts × 10. Lochinvar's own example: 110 °F → 4.92 V → 49 %. With the defaults, 60 % is about 125 °F and 80 % about 152 °F. Write 110 to AV:2 meaning °F and the boiler is told to go to its maximum. If the parameters on the boiler were changed, use those numbers instead.

The Lochinvar Crest workspace

One dashboard page for a Crest boiler with enable and setpoint from the BMS: status and blocking codes as text, inlet, outlet and flue temperature, the setpoint in force, firing rate, flame, pumps and alarm contacts — with Configuration, Coils and the setpoint command written again every 10 seconds.

1

Discover the boiler

On the BACnet tab open MS/TP on the PC's RS-485 port at the board's baud rate (or BACnet/IP behind a router) and press Discover. The boiler appears as MTR-01 BACnet.

2

Open the workspace

Workspace → Open. The file reads device 610001; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Run, then command once

BACManager starts reading the boiler by itself. On the Dashboard press Run, pick Enable + setpoint, enable the boiler and set the percentage — from then on all three are written again every 10 seconds. After BACManager restarts, command them once more.

Lochinvar Crest BACnet — FAQ

Where is the Lochinvar Crest BACnet points list?+
In Lochinvar's ModBus and BACnet Communication Instructions, 100161012_2000020084 Rev X, section 7 (BACnet memory map for Crest and Hellcat). The table on this page lists the points a BMS uses most.
What is the device instance of a Crest boiler?+
The model's base plus the MS/TP MAC address: 610000 for FB 751–2001, 670000 for FB 2501–6001 and 680000 for FCB1000–6000. MAC 50 on an FB 1001 gives 610050. The base can be changed by the integrator.
Why does my Crest stop following the BMS after a while?+
Because the BAS timer ran out: when no write arrives within the time set under Main Menu → Setup → BAS (5–120 s), the boiler goes back to its own inputs. Write the configuration and the commands again every few seconds.
How do I send a temperature setpoint over BACnet?+
Set bit 2 of AV:0 and write a percentage to AV:2. With the defaults, 20 % (2 V) is 69.8 °F and 100 % (10 V) is 179.6 °F, so 110 °F is 49 %. Read AI:7 to see the setpoint the boiler made of it.
How do Knight boilers connect to BACnet?+
Lochinvar's documents connect Knight, Knight XL, Armor and SYNC boilers through a ProtoNode FPC-N54 gateway, which reads them over Modbus RTU and serves BACnet MS/TP or BACnet/IP, with object numbers of its own. The Crest's MTR-01 BACnet board is native BACnet MS/TP.
Which baud rates does the MTR-01 BACnet board support?+
9600, 19200, 38400 and 76800, set on DIP switches 9 and 10. Use the rate of the rest of the MS/TP trunk.
