// before you start

No card to buy, one switch to check

🔌

BACnet is built in

Symbio 700 comes on the unit and speaks BACnet MS/TP and BACnet/IP itself (and Modbus RTU/TCP, LonTalk and Trane's Air-Fi wireless). You choose the protocol; there is no separate BACnet card.

📱

Configured from a phone

Settings are made in Trane's Symbio Service and Installation app over Bluetooth — tap the unit's display to switch Bluetooth on — or on the onboard display under Tools → Protocol Configuration.

⚖

BAS control must be enabled

Arbitration Method Request (MV-11100) decides whether Symbio listens to a BMS at all. In Standalone Control it ignores every BAS input; Enable External/BAS Control is the default.

// wiring

J17 for MS/TP, the RJ-45 port for IP

+−

J17

The MS/TP (or Modbus RTU) pair lands on connector J17, + and −. J17 has two sets of terminals connected inside, so the trunk comes in on one and goes on to the next unit from the other.

↔

Daisy chain

No stubs, observe polarity, terminate only the two ends of the trunk. Trane's own best-practice guide for MS/TP links is BAS-SVX51; our MS/TP troubleshooting guide covers the usual faults.

🌐

Ethernet

BACnet/IP and Modbus TCP use the controller's RJ-45 port. Across subnets you need a BBMD; see BBMD and foreign devices.

// writing to the unit

Why Symbio keeps its own setpoint

The BAS points carry a priority array, and Symbio's own setpoint sources write into the same array.

14

Stronger than 14

A wired setpoint shows up in Space Temperature Setpoint BAS at priority 15, an Air-Fi sensor's at 14. A BMS value written at 14 or weaker is ignored. Write at 8 — BACManager's default.

📱

The display writes elsewhere

A setpoint changed on the unit's display or in the mobile app goes to the point's relinquish default, not into the array. It is only used when no other valid source exists — so it can look as if the display "does nothing" on a unit the BMS controls.

↺

Falling back

When the BMS value is not valid, Symbio goes back to the Air-Fi sensor, then the wired one, then its default. Read Space Temperature Setpoint Active to see which won.

A value written at 8 stays until it is relinquished. To give control back to the local setpoint, write NULL at the same priority — the priority array explained.

The Symbio 700 rooftop workspace

One dashboard page for the unit: outdoor, discharge and space temperature, cooling capacity, the two compressors, supply fan and its speed, economizer, filter, heat/cool mode, occupancy, alarm output and a trend of space and discharge air — with the space setpoint, cooling enable, occupancy request, heat/cool mode request and diagnostic reset writable at priority 8.

1

Discover the unit

On the BACnet tab open BACnet/IP (or MS/TP on the PC's RS-485 port) and press Discover. The unit appears with its device ID.

2

Open the workspace

Workspace → Open. The file reads device 12 (rotary 012); if yours has another ID, BACManager asks which discovered device takes its place and moves every point over.

3

Run

BACManager starts reading the unit by itself. On the Dashboard press Run: the controls write only in Run mode, and only after the unit has answered.

// questions

Trane Symbio BACnet — FAQ

Where is the Trane Symbio 700 BACnet points list?+
In Trane's eLibrary: BAS-PTS001C-EN for Precedent and Axiom units, and BAS-SVP066B-EN for Voyager 3. The table on this page lists the points a BMS uses most.
How do I set the BACnet address on a Symbio 700?+
With the rotary switches: they set the MS/TP MAC address (001–127) and the device ID at the same time, at once and without a power cycle. A different device ID can be set as a software device ID in the mobile app or on the display.
What baud rate does Symbio use on MS/TP?+
76,800 by default, on both Symbio 700 and Symbio 800. Every device on the trunk must use the same rate.
Does a Symbio 700 rooftop unit need a BACnet card?+
No. BACnet MS/TP and BACnet/IP are built into the controller; you choose the protocol in the mobile app or on the display.
Why does Symbio ignore the setpoint from my BMS?+
Usually the priority: a wired setpoint sits at priority 15 and an Air-Fi one at 14, so a BMS value has to be written stronger than 14 — priority 8 works. Also check that Arbitration Method Request is not set to Standalone Control.
How do I connect to a Symbio 800?+
For setup, with a USB A/B cable and a browser at http://198.80.18.1/ — its web pages are not served over Ethernet. For BACnet, set the rotary address to 001–127 (000 turns MS/TP off) or configure BACnet/IP on Ethernet 1.
