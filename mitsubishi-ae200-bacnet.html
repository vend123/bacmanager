// before you start

No gateway, but a licence and a tool

🔑

“BACnet connection” licence

The AE-200, AE-50 and EW-50 speak BACnet/IP themselves — no separate interface. Each controller that connects to BACnet needs its own “BACnet connection” licence; apportioned energy objects need the “Charge” licence as well. All controllers on BACnet must run the same software version.

🔧

The Setting Tool must match

BACnet is configured with Mitsubishi's BACnet Setting Tool on a PC, and its version has to match the controller's: Ver. 7.3x–7.4x takes tool 3.0, 7.50–7.70 tool 3.1, 7.71–7.85 tool 3.2, 7.9 and later tool 3.3. Otherwise sending settings ends in “Version Mismatch Error”.

📋

What the controller serves

Per WT07919X08: BACnet/IP to ANSI/ASHRAE 135-2010, APDU up to 1024 octets, segmentation both ways, vendor ID 99. ReadProperty(Multiple), ReadRange, WriteProperty(Multiple), SubscribeCOV, events and time synchronisation. No Schedule or Calendar objects, no DeviceCommunicationControl or ReinitializeDevice.

// setup

Two ports, and BACnet on LAN2

LAN1 carries the air-conditioning system and the web browser, LAN2 carries BACnet. They must be on different networks and on different switches. One default gateway, set on the LAN2 page, serves both.

☑

Tick every object you need

On the Object tab each object has a Use box. Only ticked objects exist on BACnet, and the controller only creates those the group's units support. COV and event notification are off per object until you switch them on.

⇄

Offline to send, Online to run

Settings are sent only while the controller is Offline — and Offline stops its BACnet. Switching back to Online restarts the controller. It will not go Online without a valid licence, and with many groups it takes up to about ten minutes. Changing groups in the Initial Setting Tool drops it back to Offline.

🔌

Then unplug the PC

Mitsubishi's system drawings have the setting PC disconnected from the controller once the settings are made. An AE-200 controls up to 50 units itself and up to three AE-50 or EW-50 below it; each of those is a BACnet device of its own, with its own licence and Device No.

// instance numbers

The number tells you the group

Objects are per group — the indoor units that share a remote controller — not per indoor unit. The instance is six digits: object class, a fixed 1, the group 01–50, and the member number.

DigitsMeaningExample
CObject class: 0 group, 4 PI controller, 6 interlocked unit, 7 chiller system, 9 chiller unit0
1Fixed1
GGGroup 01–50 (99 = all groups)05
MMMember: what the object is09 = Room Temp

So group 5's room temperature is 010509 — analog-input 10509, because a BMS drops the leading zero. Group 12's on/off command is binary-output 11201; the collective System Forced Off for all groups is binary-value 19921.

// the rules that bite

200 ms per property

200 ms

The request interval

Mitsubishi asks the BMS to leave at least 200 ms per property between requests: after a ReadPropertyMultiple of 10 properties, wait 2000 ms before the next request. That is five properties a second, for the whole controller — 50 groups with ten points each take 100 seconds to read once.

🌡

The right set point object

Groups whose units all support dual set points in Auto use Set Temp Cool and Set Temp Heat (xx24, xx25) — or Set Temp Auto (xx26) in single-set-point Auto. Groups with older units, or with Old Model Compatibility Mode on, use Set Temp (xx10). A dual-set-point object written to a group without dual set points is answered with an error.

⚠

External input on level

If the controller's External Input Setting is ON/OFF (Level signal), do not use On Off Setup, Prohibition On Off or System Forced Off from the BMS. And during Night Purge the fan speed and ventilation mode read from BACnet are not what the unit is doing.

In BACManager a BACnet device can have a Gap, in ms per property, next to the Interval on the BACnet tab (version 1.4.6): every request to the device — poll, write, Refresh — waits until the one before it has had its properties × the gap. Set 200 for an AE-200; the free workspace brings it along for its controller. Measured against the simulated AE-200 reading the workspace's 31 points every second: without the gap BACManager asked for 31 properties a second and sent requests 2000 ms too soon after a full one; with it, about 5 a second and no request early by more than a millisecond.

The AE-200 workspace

One dashboard page for three groups on a floor: run state, mode, room temperature, thermo, alarm and filter for each, with on/off, mode and both set points to write, and the room temperatures on one trend.

1

Discover

On the BACnet tab open BACnet/IP on the network card on LAN2's network and press Discover. The controller answers with its Device No.; click it to see its objects and its Gap.

2

Open the workspace

Workspace → Open. The file reads device 3, groups 1–3, with a gap of 200 ms per property; if your controller has another Device No., BACManager asks which discovered device takes its place and moves every point — and the gap — over. For other groups, change the group digits in the tags.

3

Run

BACManager starts reading the groups by itself. On the Dashboard press Run; on/off, mode and set points are written when you change them. Groups without dual set points need Set Temp (xx10) instead.

Mitsubishi AE-200 BACnet — FAQ

Where is the Mitsubishi AE-200 BACnet points list?+
In section 5-2 of Mitsubishi Electric's AE-200/AE-50/EW-50 Instruction Book (BACnet function), WT07919X08. The table on this page lists the points a BMS uses per group.
Does the AE-200 need a BACnet gateway?+
No. The AE-200, AE-50 and EW-50 serve BACnet/IP on their LAN2 port. Each one needs a “BACnet connection” licence and is configured with Mitsubishi's BACnet Setting Tool.
What is the AE-200's default BACnet device instance?+
Device No. 3. LAN2, the BACnet port, is 192.168.2.1 from the factory and LAN1 192.168.1.1. Give every controller its own Device No.
How are AE-200 BACnet instance numbers built?+
Six digits: object class (0 for a group), a fixed 1, the group number 01–50 and the member number. Group 5's Room Temp is 010509, which a BMS shows as analog-input 10509.
How fast can a BMS poll the AE-200?+
Mitsubishi asks for at least 200 ms per property between requests — after a ReadPropertyMultiple of 10 properties, wait 2 seconds. That is about five properties a second for the whole controller.
Why can't I see an AE-200 object over BACnet?+
Only objects ticked “Use” on the BACnet Setting Tool's Object tab exist, and only those the group's units support. Tick it, send the settings while Offline, and switch back to Online.
