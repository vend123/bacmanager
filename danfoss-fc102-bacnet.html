Danfoss FC 102
BACnet Points List & Setup

How to put a VLT HVAC Drive FC 102 on BACnet MS/TP through its own RS-485 port, terminals 68 and 69: 8-30 Protocol = BACnet, the device instance every drive leaves the factory with (1), Max Masters 127, terminal 27 that coasts the motor whatever BACnet says — and the control timeout that counts writes, not reads. With a free BACManager workspace.

// before you start

BACnet MS/TP is built into the FC 102

🔌

No option card for MS/TP

The drive's standard RS-485 “FC port” on the control card speaks BACnet MS/TP once 8-30 is set to BACnet. BACnet/IP needs the separate VLT BACnet/IP MCA 125 option, which has its own object list; or put a BACnet router in front of the trunk, or read MS/TP directly from a PC — see BACnet MS/TP over RS-485.

⚡

Wiring

Terminal 68 is P+, 69 is N−. Switch S801 BUS TER. terminates the port; it is OFF from the factory and must only be moved with the drive powered down. Daisy chain only — Danfoss allows no T-drops (use repeaters), 1200 m per segment, 100–130 Ω screened twisted pair, AWG 18, kept 200 mm from motor cables. Bias: not given.

📋

What the drive serves

BTL-30670 (firmware 1.11, BACnet revision 14): B-ASC with ReadProperty, WriteProperty, dynamic device and object binding, DeviceCommunicationControl, TimeSynchronization, ReinitializeDevice. No ReadPropertyMultiple and no COV are listed. Max APDU and segmentation: not given.

A BACnet value for 8-33 Parity / Stop Bits is not given. Check on your drive.

// control

RUN/STOP Command, a reference, and which one counts

The command objects write the drive's FC-profile control word, as Danfoss' object table lists. The reference is a percentage in AV:1 or AV:2 — only one of them is active, and BV:2 decides which.

!

Our reading, check it

Danfoss does not say which BV:2 state selects AV:1, which BV:24 state coasts, or what 100 % of AV:1 is (we assume the reference range, 0–50 Hz in our simulator). The FC 102 Design Guide (MG11BC02) defines the control-word bits: bit 3 at 0 coasts, the reset acts on the leading edge. Try it on the drive with the motor safe before you rely on it.

%

AV:3 is a percentage too

Output Speed is 16-17 Speed [RPM] divided by 4-13 Motor Speed High Limit [RPM], times 100 — not of the nominal speed. For Hz read AV:25 Frequency, for amps AV:5 Motor Current.

✋

Running is BV:33

BV:4 RUN / STOP Monitor is mapped to status-word bit 1, which the Design Guide calls drive ready. Whether the motor turns is BV:33 Running (bit 11). BV:32 Bus control (bit 9) is 0 when the drive is in local control and BACnet commands are ignored.

// the rules that bite

Terminal 27, the timeout, instance 1

27

Terminal 27 coasts

Terminal 27 is “Coast inverse” from the factory and needs +24 V before the drive will start; 8-50 Coasting Select is Logic OR, so an open terminal 27 coasts the motor whatever BV:1 says. Danfoss' BACnet text asks for 8-50 = Bus [1] or Logic AND [2], with 8-01 at [0] or [2] — although its own setup table lists Logic OR. Terminal 37 Safe Stop overrides everything.

17

Writes, not reads

With 8-04 Control Timeout Function set (factory Off), the drive acts when the control word is not updated within 8-03. The 2019 guide lists the BACnet objects that retrigger it: AOs, BOs, AV0, AV1, AV2, AV4, BV1–BV5, multistate outputs. A BMS that only reads trips alarm 17 Control word timeout. The old native-BACnet manual says 8-03/8-04 are not enabled at all in its version: firmware-dependent.

#1

Every drive is instance 1

8-70 is 1 from the factory, and Max Masters is 127. Two new FC 102s on one network answer Who-Is with the same instance. Set 8-70 on each one before the BMS discovers them.

The FC 102 workspace

One dashboard page for an FC 102 on an AHU supply fan: the drive faceplate with run, trip and reference, the fan, frequency, output speed, current, power, both voltages, reference select, hand/auto, triplock, thermal values, energy and a trend.

1

Discover the drive

On the BACnet tab open MS/TP on the PC's RS-485 port at the 8-32 baud rate (or BACnet/IP behind a router) and press Discover. The drive appears with the instance from 8-70, and its objects by name.

2

Open the workspace

Workspace → Open. The file reads device 10201; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Timeout, then Start

The Input Reference 1 tag has Refresh (s) = 10: BACManager writes it again every 10 seconds, so set 8-03 well above that if you use 8-04. On the Dashboard press Run, then Start and the reference on the faceplate.

Danfoss FC 102 BACnet — FAQ

How do I enable BACnet on a Danfoss FC 102?+
Wire the trunk to terminals 68 (P+) and 69 (N−), set 8-30 Protocol = [5] BACnet, 8-31 the MS/TP address (1–127), 8-32 the baud rate (9600, 19200, 38400 or 76800), 8-70 a unique device instance and 8-72 the highest master address, then switch the drive off and on.
What is the default BACnet device instance of an FC 102?+
1, on every drive (8-70). Max Masters 8-72 is 127 and Max Info Frames 8-73 is 1. The factory baud rate is given differently in different Danfoss documents, so set 8-32 explicitly.
Which object starts the drive?+
BV:1 RUN/STOP Command. The reference is AV:1 Input Reference 1 or AV:2 Input Reference 2, whichever BV:2 REF 1 / REF 2 Select chooses. 8-50 Coasting Select has to be Bus, or terminal 27 must carry +24 V, or the motor stays coasted.
Why does the FC 102 trip with alarm 17 on BACnet?+
8-04 Control Timeout Function is set and the control word was not updated within 8-03. On BACnet the timer is retriggered by writes to the command objects (AV1, AV2, BV1–BV5, outputs), not by reads. Make 8-03 longer than the BMS's write interval, or set 8-04 Off.
Does the FC 102 support ReadPropertyMultiple or COV?+
BTL listing BTL-30670 (firmware 1.11) lists neither: ReadProperty, WriteProperty and device-management services only. Plan for polling with ReadProperty.
Does the FC 102 support BACnet/IP?+
Not on the built-in port, which is MS/TP. Danfoss offers the VLT BACnet/IP MCA 125 option, which shares 8-70 with MS/TP and has its own object list. Or reach MS/TP through a BACnet router; BACManager also reads MS/TP directly from a USB RS-485 adapter.
