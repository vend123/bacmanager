Swegon GOLD
BACnet Points List & Setup

How to bring a Swegon GOLD air handling unit onto a BMS through the BACnet/IP that is built into its IQlogic control: the External Port B address every unit leaves the factory with (10.200.1.1), the Device ID that is 0 on every unit, the one object that starts, stops and switches speed (MV 793), the points a BMS uses — and which generation the published object list belongs to. // before you start

BACnet/IP is in the unit — the list is Generation E

🔌

No gateway

GOLD RX, PX, CX and SD units speak BACnet/IP on the control unit's Ethernet port, which the menus call External Port B. The PICS lists BACnet/IP as the only data link: there is no BACnet MS/TP. The unit's EIA-485 port offers Modbus (factory), EXOline, Metasys N2 Open or LON instead. Swegon's “BACnet gateway” documents are for other products, not GOLD.

E

Which generation

GOLD has been sold as version E (2013–2017), F (from 2017) and now F/G. Swegon's published BACnet object list is for Generation E, program version 1.10 and newer. We found no public object list or EDE file for F or G. The points below are from the Generation E list; on a newer unit, read the unit's own object list and compare, or ask Swegon for the EDE file of your program version.

📋

What the unit serves

Swegon calls GOLD a B-AAC. ReadProperty(Multiple), WriteProperty(Multiple), COV, alarm and event notifications with acknowledge and GetEventInformation, an internal schedule, time synchronisation and reinitialize. Segmented requests and responses, window 32. Vendor ID 300, protocol revision 12. Max APDU and a BTL listing: not given in the documents we found.

// control

One object runs the unit: MV 793

Communication operation level is a commandable multi-state value. Operation level (MI 592) reads back what the unit actually does and why.

MV 793 stateMeaningMI 592 then reads
1 AutoDefault. The BMS does not command the speedWhatever the timer or another source decides, e.g. 24 Time channel low speed
2 Total stopStopped; no internal automatic function or external command can start it5 Communication total stop
3 Low speedRuns at the low speed set points23 Communication low speed
4 High speedRuns at the high speed set points30 Communication high speed
5 Normal stopStopped, but internal and external automatic functions may start it6 Communication normal stop
6 Extended normal stopAs normal stop, except summer night cooling7 Communication extended normal stop
!

Auto is our reading

The Generation E list calls state 1 “Auto”; the F/G terminal menu calls the factory setting “Inactive”. Neither document says in words what it hands control back to. We read it as “communication does not decide”; watch MI 592 after writing it.

8

Which priority

The analog, binary and multi-state values carry a priority array and a relinquish default, but Swegon gives no recommended priority. BACManager writes at priority 8 unless you choose otherwise. A value written stays until it is relinquished — see the priority array explained.

⚙

Set points depend on each other

The low speed air flow set point (AV 3) can go no higher than the high speed one (AV 5), which can go no higher than the max speed one (AV 7). Raise high speed first. Supply air temperature set point AV 132: 10–40 °C, default 21, used in SA regulation mode (MV 115 = 4).

// the rules that bite

Device ID 0, 10.200.1.1, Total stop

#0

Every unit is Device ID 0

Two GOLD units on one network answer Who-Is with the same device instance until someone sets it. Give each unit its own Device ID before the BMS discovers them.

IP

Every unit is 10.200.1.1

External Port B is static 10.200.1.1/24 from the factory. A second new unit on the same switch is an address conflict, and a BMS in another subnet will not find either one. Set the address first.

■

Total stop means total

Written from the BMS, Total stop also keeps the unit's own automatic functions from starting it. Use Normal stop when night heating or cooling should still run, and remember a value at priority 8 outlives the BMS that wrote it.

The GOLD workspace

One dashboard page for a GOLD with heat wheel, reheat and cooling: the unit with outdoor and supply air, air flow, cooling and reheat levels; both fans with flow, level and current; operation level, A- and B-alarm; and the BMS commands at priority 8.

1

Discover the unit

On the BACnet tab open BACnet/IP on the PC's network card in the unit's subnet and press Discover. From another subnet, register with the site's BBMD as a foreign device. The unit appears with its Device ID.

2

Open the workspace

Workspace → Open. The file reads device 20101; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Run

On the Dashboard press Run. The commands write at priority 8 only in Run mode and only after the unit has answered. Set MV 793 back to Auto to hand the unit back to its own timer.

Swegon GOLD BACnet — FAQ

How do I enable BACnet on a Swegon GOLD?+
BACnet/IP is built in. In the Communication menu (hand-held terminal or web page) give External Port B an address in the BMS network and set a unique Device ID under BACnet IP; the port is 47808. The manual lists no separate BACnet on/off setting.
What are the GOLD's default IP address and device instance?+
External Port B is 10.200.1.1 with mask 255.255.255.0 and DHCP off; the BACnet Device ID is 0 and the UDP port 47808 — the same on every unit.
Which BACnet object starts and stops a GOLD?+
MV 793 Communication operation level: 1 Auto, 2 Total stop, 3 Low speed, 4 High speed, 5 Normal stop, 6 Extended normal stop. MI 592 Operation level shows the state the unit is actually in and its source.
Is there a BACnet points list for GOLD version F or G?+
We found none published. Swegon's public list is for Generation E, program version 1.10 and newer. On an F or G unit, read the object list from the unit and compare, or ask Swegon for the EDE file of your program version.
Does the GOLD support BACnet MS/TP?+
No. The PICS lists BACnet/IP as the only data link. The unit's EIA-485 port speaks Modbus, EXOline, Metasys N2 Open or LON.
How do I read and reset GOLD alarms over BACnet?+
BI 13 and BI 14 show any A- or B-class alarm, AI 604–613 the triggered alarm numbers, and each alarm also has its own binary input from BI 501. BV 1 Alarm reset resets all active alarms. The unit also sends alarm notifications through notification classes 0 (A) and 1 (B).
