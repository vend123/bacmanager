// before you start

Three things the chiller needs

🔌

A BACnet communication module

The MicroTech III controller speaks BACnet through an add-on module that clips onto its left side: one for MS/TP (POL904) or one for BACnet/IP (POL908). It is fitted at the factory or in the field; Daikin's module manuals are IM 967 (MS/TP) and IM 966 (IP).

🔑

Network control at the keypad

Chiller Local/Network can only be set on the keypad. In Local the chiller reads fine but ignores every network enable, mode, setpoint, limit and clear-alarm write — without returning an error. Set it to Network.

🏷

A unique device instance

The controller computes its first device instance from the module's MAC address (MS/TP) or production code (IP), so read it on the keypad or with a Discover. Two chillers must not share one; change it on the keypad and cycle power.

// keypad setup

Two things catch people out. A field upgrade of the chiller's application software puts the network parameters back to their defaults, so a chiller that vanished after a service visit may simply be on MAC 18 again. And on BACnet/IP the keypad shows Act IP as 0.0.0.0 when the network cable was not connected at power-up.

// ms/tp wiring

RS-485 to the MS/TP module

+−

Three wires

The module's network plug takes +, − and Ref. Daisy-chain the trunk, no stubs, and ground the shield at one point only. The port is isolated and is a 1/8 unit load.

Ω

Termination that survives a power cut

The keypad's Term Resistor is a software resistor: it disappears when the controller is off, and the whole trunk with it. Daikin recommends a physical 120 Ω resistor at both ends instead.

↔

Length

Up to about 4000 ft (1200 m) at 76800 baud without a repeater. If the chiller drops off the trunk now and then, see the MS/TP troubleshooting guide.

// writing to the chiller

Priority 8, and the writes it ignores

The commandable points carry a 16-slot priority array. The value that applies is the one in the strongest slot that holds something.

8

Write at priority 8

The controller keeps priorities 1 and 5 for its own application: a BACnet write there fails. If a LonWorks or Modbus module is fitted as well, they write at 8, and Daikin says BACnet must write at 8 or stronger. BACManager writes at 8 unless you choose otherwise.

🚫

Accepted, then ignored

In Local (BI:3 = 1) the controller takes the write and does nothing with it. A cool setpoint below the setpoint set at the unit does not apply either, and the mode request is only used when the unit's available modes include Ice.

⚠

Not every alarm clears

ClearAlarm cannot clear the manual-reset faults — low evaporator pressure, high condenser pressure, high motor temperature, freeze protection and mechanical pressure trips. Those need someone at the chiller.

A value written at priority 8 stays there until it is relinquished, also after the BMS that wrote it is gone. To hand control back, write NULL to the same slot — see the priority array explained.

Daikin MicroTech III BACnet — FAQ

Where is the Daikin MicroTech III BACnet points list?+
In Daikin Applied's document ED 15120-11, MicroTech Chiller Unit Controller Protocol Information, on daikinapplied.com. The table on this page lists the points a BMS uses most; ED 15120-11 has every object per model.
Does a MicroTech III chiller need a BACnet card?+
Yes. BACnet goes through a communication module clipped onto the controller: POL904 for BACnet MS/TP or POL908 for BACnet/IP. It can be ordered with the chiller or fitted later.
What is the default device instance?+
The controller computes it from the module's MAC address or production code, so it differs per chiller. The module manuals give 368136 for MS/TP and 1579312 for BACnet/IP. Read the real one on the keypad or with a Discover.
What are the default MS/TP settings?+
MAC address 18, 38400 baud, Max Master 127. They are changed in the keypad's BACnet MSTP Setup menu and take effect after Apply, which restarts the controller.
Which BACnet priority should I write the setpoint at?+
Priority 8. Priorities 1 and 5 are reserved for the controller and writes there fail; with a LonWorks or Modbus module also fitted, BACnet has to write at 8 or stronger.
Why does the chiller ignore my BACnet setpoint?+
Most often Chiller Local/Network is set to Local, which only the keypad can change. A network cool setpoint below the setpoint set at the unit is also not applied. Compare AV:4 with the active setpoint AV:5.
Does the MicroTech III support COV?+
Yes. Daikin's PICS lists SubscribeCOV, ReadPropertyMultiple, WritePropertyMultiple, intrinsic alarming, scheduling and trend logs. A change of COV increment needs a power cycle to stick.
