Yaskawa HV600
BACnet Points List & Setup

How to put a Yaskawa HV600 drive on BACnet MS/TP through its built-in RS-485 terminals: H5-08 = 3, a device instance written in hexadecimal across two parameters (factory: 1), the run and reference sources that leave the factory on terminals and analog input — and the bitmapped objects that must not be mixed with the single-bit ones. With a free BACManager workspace.

// before you start

BACnet MS/TP is built into the HV600

🔌

No option card for MS/TP

The HV600 speaks BACnet MS/TP on terminal block TB6 as a B-ASC; up to 127 drives per MS/TP segment, more behind a router. BACnet/IP needs the JOHB-SMP3 option, which has its own, different object list — this page is about the embedded MS/TP port. For BACnet/IP without the option put a BACnet router in front of the trunk, or read MS/TP directly from a PC — see BACnet MS/TP over RS-485.

⚡

Wiring

TB6: D+ and D− for the data pair, AC for signal ground. Shielded cable, shield to the drive's ground terminal, kept apart from power wiring. DIP switch S2 ON switches in the built-in terminating resistor — on the drives at both physical ends only, OFF on all others. Bias: not given.

📋

What the drive serves

Per the PICS and BTL-30529 (firmware 2.01, BACnet revision 14): ReadProperty, ReadPropertyMultiple, WriteProperty, WritePropertyMultiple, COV and COVP, dynamic binding, DeviceCommunicationControl, ReinitializeDevice, TimeSynchronization. The PICS gives no segmentation window, so plan for none; max APDU: not given.

Yaskawa's procedure: set the H5 parameters, then switch the drive off and wait until the keypad display is dark, or set H5-20 = 1 Reload Now — but H5-20 reloads only H5-01, H5-02, H5-03 and H5-06. The Device Object Name (20 characters) and Location are written over BACnet, not on the keypad.

!

Bits or bitmap, not both

Yaskawa: when you use AV1 Operation Cmd, do not use BV1–BV11 or AV5; when you use AV5 Reference Select Cmd, do not use AV1, BO4 or BV9–BV11; when you use AV4 MF Output Cmd, do not use BO1–BO3 or BV12. They write the same registers. The workspace uses the single bits.

OR

Inputs are ORed

The multi-function input commands from BACnet (AV1 bits 4–A, BV7–BV11) and the drive's terminals S1–S7 are combined with a logical OR. A terminal that is on cannot be switched off from BACnet.

✋

HAND, OFF, AUTO

With b1-02 = 8 the drive takes BACnet's run command in AUTO mode only; HAND on the keypad uses the keypad reference. BV43 Run Command Mode and BV42 Frequency Ref Mode read COM or LOCAL. AV39 Drive HOA Status exists, but its values are not given in the manual.

// the rules that bite

Factory sources, hex instance, comm loss

b1

Not on serial from the factory

b1-01 is Analog Input and b1-02 AUTO Command + Term Run out of the box. BACnet reads everything, writes are accepted — and the motor follows terminals and analog input. Set b1-01 = 2 and b1-02 = 2 or 8.

#1

Every drive is instance 1

H5-14 = 0001 and H5-15 = 0000 on every new HV600. The instance is entered in hex: typing “6001” into H5-14 gives instance 24577 (6001 hex). Convert first.

CE

Communication loss

With H5-05 = 1 the drive flags CE when no data arrives from the master within H5-09 (2.0 s). H5-04 decides: 3 Alarm Only from the factory — the fan keeps running at the last command; 0 ramp, 1 coast, 2 fast stop (a fault); 4 run at H5-34. The manual calls it a Modbus error but lists these parameters in the BACnet setup.

Fault codes from the Technical Reference's fault-trace table (a selection); that AV42 shows them as plain numbers is our reading. Parameters not in the list: write the Modbus register (decimal) to AV29, then read AV30; to write, put the value in AV30 and set BV55 (RAM) or BV56 (RAM and EEPROM — at most 100,000 times). COV works only on objects that are neither commandable nor writable. Commandable objects keep a priority array and the drive uses the highest-priority value; which priority a BMS should use, and the relinquish defaults, are not in the manual. BACManager writes at priority 8 unless you choose otherwise.

The HV600 workspace

One dashboard page for an HV600 on an exhaust fan: the drive faceplate with run, fault and the Hz reference, the fan, frequency, speed, current, power, both voltages, reference and run source, the communication error, HOA status, ramps, energy and a trend.

1

Discover the drive

On the BACnet tab open MS/TP on the PC's RS-485 port at the H5-02 baud rate (or BACnet/IP behind a router) and press Discover. The drive appears with the instance from H5-14/H5-15, and its objects by name.

2

Open the workspace

Workspace → Open. The file reads device 6001; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

AUTO, then Start

With b1-01 = 2, b1-02 = 8 and the keypad in AUTO, press Run on the Dashboard, then Start and the frequency on the faceplate. Run Command Mode should read COM.

Yaskawa HV600 BACnet — FAQ

How do I enable BACnet on a Yaskawa HV600?+
Wire TB6 (D+, D−, AC), set H5-08 = 3 BACnet, H5-01 the MS/TP address, H5-02 the baud rate, H5-14/H5-15 the device instance in hex and H5-23 the highest master address, then power the drive off until the keypad is dark and on again.
What is the default BACnet device instance of an HV600?+
1 (H5-14 = 0001, H5-15 = 0000), on every drive. The factory node address H5-01 is 1F hex (31), the baud rate 9600, Max Master 127 and Max Info Frames 3.
Which object starts the HV600?+
BV1 Run FWD Cmd (BV2 for reverse), with the reference in AV2 Frequency Cmd in Hz — once b1-01 = 2 and b1-02 = 2, or 8 with the keypad in AUTO. AV1 Operation Cmd is the same command register as a bitmap; use one or the other.
What happens when the HV600 loses BACnet communication?+
After H5-09 (2.0 s) without data from the master it shows CE. From the factory H5-04 = 3 Alarm Only, so the drive keeps running; set H5-04 to 0, 1 or 2 to stop it, or 4 to run at the H5-34 frequency.
Does the HV600 support ReadPropertyMultiple and COV?+
Yes, per its PICS and BTL-30529: ReadPropertyMultiple, WritePropertyMultiple and COV. COV is available only on objects that are neither commandable nor writable.
Is this the same object list as the JOHB-SMP3 BACnet/IP option?+
No. This page uses the embedded MS/TP list from the HV600 Technical Reference. The JOHB-SMP3 option has its own manual and object list for BACnet/IP: much of it matches, but it adds objects such as a Network Port object and external-drive gateway values; check that manual if your drive has the option, or read the object list from the drive itself.
