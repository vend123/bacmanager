// before you start

Which Conquest, which port

🔌

BAC-9000A is the VAV family

The BAC-9001A is the pressure-independent VAV controller-actuator (single or dual duct), the BAC-9021A the pressure-dependent one. The “A” suffix marks KMC's Gen6 hardware. The BAC-9300A series is the unitary controller, not covered here. Each model comes with an MS/TP port or, on “E” models such as the BAC-9001ACE, two Ethernet ports.

⚡

MS/TP wiring

One EIA-485 port, 9.6 to 115.2 kbaud, up to 1200 m of 18 AWG shielded twisted pair. Turn the EOL switch on only in the two end controllers (they ship off). KMC allows 128 masters per network but recommends about 30 controllers; beyond 31 devices or 1220 m use a repeater or a router. More in BACnet MS/TP over RS-485.

📋

What the controller serves

B-AAC: ReadProperty, ReadPropertyMultiple, WriteProperty and WritePropertyMultiple, COV, alarms and events, schedules, trend logs, segmentation (window 7). That is from KMC's 2017 PICS and BTL listing BTL-30013, which cover the earlier Gen5 models; the Gen6 data sheet says BTL-certified as a B-AAC.

// writing setpoints

Write the occupied setpoints, read the active ones

KMC's factory programs decide the setpoint in force from the occupancy. A BMS that writes the wrong object sees its value replaced.

Unoccupied= AV7 UNOCC CL STPT (80)= AV8 UNOCC HT STPT (64)AV7 / AV8 for night setback
↺

The program overwrites

The guide says the controller places AV5–AV8 into AV3/AV4 whenever the occupancy changes, and that a setpoint entered at the NetSensor (through AV3/AV4) lasts only for a limited time or until the next occupancy change. So treat AV3/AV4 as read-only from the BMS. Values in °F are the factory defaults in English units.

4°

Minimum differential

AV11 MIN STPT DIFF (4 °F) keeps heating below cooling. KMC's example: with heating at 70, lowering the occupied cooling setpoint to 71 makes the controller move occupied heating to 67. Write cooling and heating as a pair and read both back.

8

Which priority

KMC's PICS gives the value objects a priority array and relinquish default, but no document we found says which priority a BMS should use. BACManager writes at priority 8 unless you choose another. A cold start returns every present value to its relinquish default.

Occupancy normally comes from the controller's own BACnet Schedule object, which a BMS can edit like any other — see the schedule editor. KMC also says occupancy “can be commanded” by another BACnet device, without naming the object; MSV1 OCCUPIED MODE is the obvious candidate, and the free workspace writes it, but try it on your controller first.

// the rules that bite

Units, applications, and the K factor

°F

Units reset the box

The factory objects are in °F and cfm. Switching to Metric — or changing the application — in RSTR restores the Setpoint, System and Balance menus to factory defaults (communication settings and passwords stay). Choose application and units first, let the controller restart for at least 30 s, then commission.

K

The K factor makes the flow

Airflow is calculated from the box's differential pressure and the K factor in AV18 PRI K FACT (904 from the factory). With the wrong K factor every cfm reading is wrong. KMC's guide lists K factors per box in an appendix; balancing with a flow hood then sets the correction factors.

?

Read the object list

The objects depend on the model and the application chosen in RSTR, and can be created and deleted with KMC's tools. Read the device's object list instead of assuming a table, and don't reuse KMC's default objects for custom programs: a firmware upgrade can overwrite them.

The four AHU flags, as the guide defines them: NEED AHU is on when the box is occupied or in standby, or unoccupied with a loop at 100 %, and off when both loops fall below 5 %. NEED COLDER SPLY and NEED HOTTER SPLY come on with the damper fully open and the cooling (or heating) loop above 95 % for 30 minutes, and go off below 90 %. NEED MORE STATIC means the damper is fully open and the airflow still cannot reach its setpoint. The dual-duct application adds secondary duct objects, and the BAC-9021A pressure-dependent application has its own table.

The Conquest VAV workspace

One dashboard page for a single-duct VAV box: the room faceplate with space temperature, the occupied setpoints and occupancy, the damper, airflow against its setpoint, discharge air, reheat, the active setpoints, the AHU flags, the writable airflow range and two trends.

1

Discover the box

On the BACnet tab open BACnet/IP for an “E” model, or MS/TP on the PC's RS-485 port at the trunk's baud rate (or through a router), and press Discover. The controller appears with the instance set in D ID.

2

Open the workspace

Workspace → Open. The file reads device 30214; if yours has another instance, BACManager asks which discovered device takes its place and moves every point over.

3

Run, then write

On the Dashboard press Run. The faceplate's + and − write the occupied setpoints AV5/AV6 at priority 8; the active setpoints next to the damper show what the program made of them. If the controller was restored to Metric, change the unit labels on the elements and the trend ranges to match.

KMC Conquest VAV BACnet — FAQ

How do I set the BACnet address of a KMC Conquest VAV controller?+
With an STE-9000 series NetSensor: hold Up and Down for six seconds, enter the level 2 password, then Configuration → COMM sets D ID (device instance), MAC and BAUD. KMC Connect, TotalControl, Converge or the KMC Connect Lite NFC app do the same; Max Master needs one of the tools.
What is the default IP address of a Conquest “E” controller?+
192.168.1.251 with mask 255.255.255.0 and gateway 192.168.1.1. It is changed with KMC's software or the controller's web pages, not from the NetSensor. KMC's guide does not give a factory device instance or MS/TP MAC.
Which object should a BMS write to change the room setpoint?+
The occupied setpoints AV5 OCC CL STPT and AV6 OCC HT STPT (and AV7/AV8 for unoccupied). AV3/AV4, the active setpoints, are recalculated by KMC's program when the occupancy changes.
Where is the airflow in the object list?+
AV24 PRI ACTUAL FLOW is the corrected airflow, AV22 PRI FLOW STPT its setpoint and AV50 DAMPER POSITION the damper, all in the single-duct BAC-9001A application. The range comes from AV13–AV16, in cfm unless the controller was set to Metric.
Can I switch the controller to °C?+
Yes, in the NetSensor's RSTR menu (English, Metric or mixed). Changing units — or the application — restores the Setpoint, System and Balance settings to factory defaults, so do it before commissioning.
Is the BAC-9001A BTL listed?+
KMC's data sheet says the BAC-9000A series is BTL-certified as a B-AAC. The BTL listing we found, BTL-30013 from 2017, covers the earlier BAC 9001 and BAC 9021 models.

Where this comes from

KMC Controls: KMC Conquest Gen6 Controller Application Guide AG250415B (2025; MS/TP and Ethernet connections, NetSensor menus, VAV sequences, BAC-9001A object tables), data sheet BAC-9000A Series BACnet VAV Controller-Actuators 925-035-02C (2024), and the PICS KMC Conquest Controllers Combined Rev B and BTL listing BTL-30013 (both February 2017, firmware R1.1.0.0). Get the documents from kmccontrols.com and check them against your controller's firmware and application. Where the guide disagrees with itself we followed the object table: two passages map the NetSensor setpoints to AV4/AV5 while the table, the sequences and a third passage use AV3/AV4, and the text gives a 74 °F changeover default where AV37 lists 72. The factory device instance, MAC, baud rate and a recommended write priority are not in these documents; the occupancy object is our reading.
